# Patchwork Pirates Client

## How to play (Phase 0)

Terminal 1:

```sh
pnpm --filter @patchwork/server start
```

Terminal 2:

```sh
pnpm --filter @patchwork/client dev
```

Open the printed Vite URL. Move with WASD or arrow keys, dash with Space or
Shift, and hold E to interact. The cutlass fights on its own.
